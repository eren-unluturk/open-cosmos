# Backend reference

Flask, server-rendered, no accounts. Owner: Tobi (routes, gate, deployment); data loading, Supabase and security checks added by Eren. This page describes the code as it is today.

## Data
`src/data/*.json` is generated by `scripts/` and committed (1,085 entries, 72 guides, 26 lessons, 76 coding problems, plus translation overlays). Counts and tables: `docs/STATS.md`. `src/store.py` loads everything once and merges the translation overlays at load time (all or nothing per item and language, so a page never mixes two languages).

| File | What |
|---|---|
| `learn.json`, `build.json` | CC0 link lists (676 + 352 entries after link cleanup) |
| `kids.json` | CS Unplugged entries (57, CC BY-SA 4.0), kept apart from the CC0 files |
| `guides.json`, `lessons.json`, `problems.json` | English-only content |
| `*_translated.json`, `lessons_overlay.json`, `problems_overlay.json` | es/ar/hi/pt text keyed by the English text |
| `categories_translated.json`, `progress_text.json` | headings and progress strings |

## Modules (`src/`)
| Module | Role |
|---|---|
| `app.py` | Routes, session, headers, language and level handling. |
| `store.py` | Loads the catalogue from the bundled JSON, or from Supabase when `CONTENT_SOURCE` allows it and `SUPABASE_URL` + `SUPABASE_ANON_KEY` are set (3 s timeout, 10-minute cache, falls back to JSON on any error, empty result or schema mismatch). |
| `content_rows.py`, `supabase_client.py` | The row format shared by the store, `seed_supabase.py` and `verify_supabase.py`; a tiny REST client. |
| `gate.py` | Safety gate: `kid-safe` always visible; `ask-a-grown-up` only when the session's grown-up flag is on; `adult-only` never. Missing or unknown safety means `ask-a-grown-up` (fail closed). |
| `guide.py` | The "What should I learn?" path: rule-based, kid-safe entries only, age-fit, goal and level, easier first, up to 6. **No AI call.** |
| `tracks.py` | Groups entries into galaxies (subjects), systems (tracks) and stops. |
| `delivery.py` | Classifies entries as link-only or open-content and builds attribution text. |
| `problems.py` | Public view of coding problems (never exposes the solution in the page) and the test runner helpers. |
| `feedback.py` | Cleans and validates grown-up feedback and rate-limits it (5 per hour per session). |
| `csp.py` | Content-Security-Policy and the other security headers (one source for Flask and `vercel.json`). |
| `ui_strings.py`, `i18n_*.py` | Interface strings in en/es/ar/hi/pt; missing keys fall back to English. |

## Routes
| Route | Purpose |
|---|---|
| `GET /` | redirects to the best language from `Accept-Language` |
| `GET /<lang>/` | home |
| `GET /<lang>/<side>` | `learn`, `build`, `kids` lists with `?q=`, `?age=`, `?topic=`, `?level=` |
| `GET /<lang>/entry/<id>` | entry page: guide slides, timeline, leaving-our-site notice, Explore next |
| `GET /<lang>/lessons`, `/lesson/<id>` | adapted lessons with the CC BY-SA attribution box |
| `GET /<lang>/problems`, `/problem/<id>` | coding problems (code runs in the browser) |
| `GET /<lang>/guide` | "What should I learn?" |
| `GET /<lang>/constellation`, `/galaxy/<id>`, `/galaxy/<id>/<id>`, `/library`, `/me`, `/catalogue`, `/howto/<kind>` | map, search and progress pages |
| `GET /<lang>/accessibility` | accessibility statement |
| `GET/POST /<lang>/feedback` | grown-ups' feedback (404 unless the grown-up flag is on) |
| `POST /<lang>/prefs`, `POST /grownup` | level choice, grown-up switch (session only) |
| `GET /api/entries`, `/api/catalogue`, `/api/problems...` | JSON (same safety gate; the public problem JSON never includes solutions) |
| `GET /healthz` | `{"ok": true}` |

Rules: 404 on an unknown language, side or id; every query value is checked against an allow-list; `q` is capped at 80 characters; hidden entries 404 (they are not just hidden in the list).

## Safety gate and the guide
- Default view: `kid-safe` only. "I'm a grown-up" sets `session["adult"]` (signed cookie, session only, nothing stored) and reveals `ask-a-grown-up`. `adult-only` is never shown, even with the flag. The guide ignores the flag and uses `kid-safe` only.
- Guide: pool = kid-safe entries whose `age_group` is at or below the chosen age; goal topic first, then `general`; chosen level first, then lower; ages 5-10 get Beginner only; easier first; at most 6, never padded with unsafe entries. Coverage gaps are real and listed in `docs/PLAN.md`.

## Security (details in `docs/SECURITY.md`)
Signed session cookie (`HttpOnly`, `SameSite=Lax`, `Secure` when `COOKIE_SECURE=1`); every POST is refused when the browser says it came from another site; feedback has a CSRF token, honeypot, size limits and a rate limit; strict Content-Security-Policy; Jinja autoescape with no `|safe`; no AI or paid API at runtime.

## Configuration (environment only, never committed)
`SECRET_KEY` (required in production), `COOKIE_SECURE=1`, `CONTENT_SOURCE` (`auto` default, `json`, `supabase`), `SUPABASE_URL`, `SUPABASE_ANON_KEY`. `SUPABASE_SERVICE_KEY` exists only in a local `.env` for seeding and is **never deployed**.

## Deploy
Vercel: `index.py` re-exports `src/app.py`'s `app`; static files in `public/static/`; `.python-version` pins 3.12. See `docs/DEPLOY.md`. Local: `.venv/bin/flask --app src/app run -p 5001`.

## Tests
`.venv/bin/python -m unittest discover -s tests` (Python, includes data checks, i18n key parity, the safety gate in both content modes, security and accessibility checks) and `node --test tests/js/*.test.js` (settings module). `python scripts/smoke_remote.py BASE_URL` checks a running site.
